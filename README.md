# بازی سنگ کاغذ قیچی دو نفره (نسخه هوشمند با مدل خودآموز)

## چرا این نسخه فرق داره؟
نسخه‌ی قبلی از رنگ پوست استفاده می‌کرد که به نور خیلی حساس بود.
این نسخه از **MediaPipe Hand Landmarker** برای پیدا کردن دقیق ۲۱ نقطه‌ی
اسکلت دست استفاده می‌کند (کاملاً مستقل از نور و رنگ پوست)، و به‌جای
قوانین ثابت، یک **مدل یادگیری ماشین (RandomForest)** حرکت را تشخیص
می‌دهد که **خودت آن را با دست خودت آموزش می‌دهی**.

## نصب (فقط یک‌بار)
```bash
pip install opencv-python mediapipe scikit-learn joblib numpy
```

## مرحله ۱: آموزش مدل با دست خودت
```bash
python train_gestures.py
```
- دستت را جلوی دوربین به شکل **سنگ**، **کاغذ** یا **قیچی** بگیر.
- کلید متناظر را بزن تا نمونه ثبت شود:
  - `1` → سنگ (مشت)
  - `2` → کاغذ (دست باز)
  - `3` → قیچی (دو انگشت)
- از هر حالت **حداقل ۱۵ نمونه** لازم است؛ برای دقت بهتر **۴۰-۵۰ نمونه**
  با زاویه و فاصله‌ی کمی متفاوت از دوربین بگیر (این باعث می‌شود مدل در
  حالت واقعی بازی هم درست تشخیص بدهد).
- اگر اشتباه ثبت کردی، `Backspace` آخرین نمونه را حذف می‌کند.
- وقتی نمونه‌ها کافی بود، کلید `T` را بزن تا مدل آموزش ببیند و در فایل
  `gesture_model.pkl` کنار همین اسکریپت‌ها ذخیره شود.
- دقت مدل روی داده‌ی تست در کنسول چاپ می‌شود.
- خروج: `Q` یا `ESC`

> نکته: بار اول که این اسکریپت (یا rps_game.py) را اجرا کنی، یک فایل
> مدل تشخیص دست از گوگل (`hand_landmarker.task`، حدود ۸ مگابایت)
> به‌صورت خودکار دانلود می‌شود؛ فقط برای همین یک‌بار به اینترنت نیاز است.

## مرحله ۲: اجرای بازی
```bash
python rps_game.py
```
- هر بازیکن دست خودش را در نیمه‌ی خودش از تصویر (چپ = بازیکن ۱،
  راست = بازیکن ۲) جلوی دوربین می‌گیرد.
- `SPACE` → شروع دور جدید (شمارش معکوس ۳-۲-۱، سپس ثبت حرکت هر دو نفر)
- `R` → ریست امتیازها
- `Q` / `ESC` → خروج

## اگر دقت هنوز کافی نبود
- دوباره `train_gestures.py` را اجرا کن و نمونه‌ی بیشتری (با نورهای
  مختلف، زوایای مختلف) اضافه کن؛ هرچه داده بیشتر و متنوع‌تر باشد،
  دقت مدل در بازی واقعی بالاتر می‌رود.
- مطمئن شو نور محیط کافی و دست‌ها کاملاً داخل کادر دید دوربین است.

## ساختار فایل‌ها
| فایل | نقش |
|---|---|
| `hand_utils.py` | تشخیص اسکلت دست با MediaPipe و استخراج ویژگی |
| `ui_kit.py` | مجموعه‌ی توابع طراحی و ظاهر (پنل، آیکون، گرادیان، ...) |
| `train_gestures.py` | جمع‌آوری نمونه و آموزش مدل با دست خودت |
| `rps_game.py` | بازی نهایی که از مدل آموزش‌دیده استفاده می‌کند |
| `gesture_model.pkl` | مدل آموزش‌دیده (بعد از اجرای مرحله ۱ ساخته می‌شود) |
| `hand_landmarker.task` | مدل تشخیص اسکلت دست (بار اول خودکار دانلود می‌شود) |
