# بازی سنگ کاغذ قیچی دو نفره (نسخه‌ی یکپارچه با راهنمای کامل درون‌برنامه)

## ⚠️ اگر از نسخه‌ی قبلی آپدیت کردی
منطق تشخیص حرکت عوض شده (نرمال‌سازی چرخشی + augmentation) و مدل قبلی
(`gesture_model.pkl`) دیگر با کد جدید سازگار نیست. **قبل از بازی، حتماً
یک‌بار دیگر آموزش بده** (کلید `T` داخل بازی، نمونه بگیر، کلید `G`).
فایل قدیمی مدل را هم می‌توانی پاک کنی، اشکالی ندارد اگر پاک نکنی چون با
`G` جایگزین می‌شود.

## چی جدیده؟
- دیگر لازم نیست فایل جدا برای آموزش اجرا کنی؛ همه‌چیز (تمرین + بازی) داخل
  همان یک برنامه (`rps_game.py`) است.
- وقتی مدلی وجود نداشته باشد، به‌جای یک پیام کوتاه، یک **صفحه‌ی راهنمای
  کامل قدم‌به‌قدم** نشان داده می‌شود.
- یک **اسکوربورد** بزرگ بالای صفحه با امتیاز زنده، شماره‌ی دور، و آیکون
  جام برای بازیکن جلوتر.
- یک **نوار راهنمای کلیدها** همیشه پایین صفحه است که بسته به حالت فعلی
  بازی (تمرین/آماده/شمارش‌معکوس/نتیجه/پایان مسابقه) خودش را عوض می‌کند.
- **پایان واقعی بازی**: اولین بازیکنی که به ۵ امتیاز برسد، برنده‌ی
  مسابقه اعلام می‌شود و صفحه‌ی برد بزرگ با جام نشان داده می‌شود.

## نصب (فقط یک‌بار)
```bash
pip install opencv-python mediapipe scikit-learn joblib numpy
```

## اجرا
```bash
python rps_game.py
```
همین! همه‌چیز از داخل خود بازی مدیریت می‌شود.

### بار اول که اجرا می‌کنی (بدون مدل آموزش‌دیده)
یک صفحه‌ی راهنما با ۶ قدم شماره‌گذاری‌شده باز می‌شود:
1. کلید `T` را بزن تا وارد «حالت تمرین» شوی.
2. دستت را جلوی دوربین به شکل سنگ / کاغذ / قیچی بگیر.
3. کلید `1` (سنگ) / `2` (کاغذ) / `3` (قیچی) را بزن تا آن حالت ذخیره شود.
4. از هر حالت حداقل ۱۵ نمونه (ترجیحاً ۴۰+ با زاویه‌های مختلف) جمع کن.
5. کلید `G` را بزن تا مدل روی دست تو آموزش ببیند و ذخیره شود.
6. کلید `SPACE` را بزن و شروع کن به بازی با دوستت!

> نکته: بار اول اجرا، یک فایل مدل تشخیص اسکلت دست از گوگل
> (`hand_landmarker.task`) خودکار دانلود می‌شود (~۸ مگابایت، فقط یک‌بار).

## کنترل‌های کامل
| کلید | زمانی که فعاله | عملکرد |
|---|---|---|
| `T` | تقریباً همیشه | ورود به حالت تمرین (برای آموزش دوباره یا بهتر کردن مدل) |
| `N` | آماده / بعد از نتیجه / پایان مسابقه | تغییر اسم بازیکن‌ها |
| `C` | فقط در حالت آماده | جابه‌جایی بین دو‌نفره / تک‌نفره در برابر کامپیوتر |
| `M` | همیشه | قطع/وصل صدا |
| `1` / `2` / `3` | داخل حالت تمرین | ثبت نمونه‌ی سنگ / کاغذ / قیچی |
| `Backspace` | داخل حالت تمرین | حذف آخرین نمونه |
| `G` | داخل حالت تمرین (بعد از نمونه‌ی کافی) | آموزش و ذخیره‌ی مدل |
| `ESC` | داخل حالت تمرین | لغو و بازگشت |
| `SPACE` | آماده / بعد از نتیجه / پایان مسابقه | شروع دور یا مسابقه‌ی جدید |
| `D` | حالت آماده‌ی بازی | نمایش/عدم‌نمایش درصد اطمینان مدل برای هر سه حرکت (دیباگ) |
| `R` | تقریباً همیشه | ریست کامل امتیاز |
| `Q` / `ESC` | خارج از حالت تمرین | خروج از بازی |

نوار پایین صفحه همیشه دقیقاً همین کلیدهای مرتبط با وضعیت فعلی را نشان می‌دهد،
پس نیازی به حفظ کردن این جدول نیست.

## قابلیت‌های جدید این نسخه
- **حالت تک‌نفره در برابر کامپیوتر**: کلید `C` را در صفحه‌ی آماده بزن تا
  بین «دو نفره» و «در برابر کامپیوتر» جابه‌جا شوی. در این حالت فقط یک
  دست لازم است؛ حریف (کامپیوتر) حرکتش را تصادفی انتخاب می‌کند.
- **صدا و افکت**: تیک برای شمارش معکوس، بیپ برای شروع ثبت، آرپژ برای
  برد، و فانفار برای پیروزی در کل مسابقه. کلید `M` صدا را قطع/وصل می‌کند.
- **ذخیره‌ی اسم و آمار بین اجراها**: اسم آخرین بازیکن‌ها و رکورد
  برد/باخت هرکدام (در حالت دو‌نفره) در فایل `game_data.json` ذخیره
  می‌شود و هر بار که برنامه را باز کنی، خودش لود می‌شود.
- **بهبود دقت با هموارسازی زمانی**: به‌جای تصمیم‌گیری روی فقط یک فریمِ
  لحظه‌ای، وقتی شمارش معکوس به صفر برسد یک «پنجره‌ی ثبت» نیم‌ثانیه‌ای
  باز می‌شود (نوشته‌ی HOLD! روی صفحه) و چند فریم پشت‌سرهم جمع‌آوری و
  میانگین‌گیری می‌شود؛ این باعث می‌شود اگر دقیقاً همان لحظه دست کمی در
  حال حرکت بود، تشخیص خراب نشود.
- **تبدیل به فایل اجرایی exe**: اسکریپت `build_exe.bat` را (روی ویندوز،
  بعد از `pip install pyinstaller`) اجرا کن تا یک `RockPaperScissors.exe`
  مستقل بسازی که نیازی به نصب پایتون روی سیستم مقصد ندارد.


هر وقت (توی صفحه‌ی آماده، بعد از نتیجه، یا پایان مسابقه) کلید `N` را بزن؛
با کیبورد اسم هر بازیکن را تایپ کن (حروف/اعداد انگلیسی)، با `TAB` بین
اسم بازیکن ۱ و ۲ جابه‌جا شو، و با `ENTER` تأیید کن. اسم‌ها همه‌جا (اسکوربورد،
پنل‌های کناری، صفحه‌ی پایان مسابقه) جایگزین "PLAYER 1 / PLAYER 2" می‌شوند.

## اگر دقت هنوز کافی نبود
- کلید `D` را در حالت آماده‌ی بازی بزن؛ زیر هر بازیکن درصد اطمینان مدل
  به هر سه حرکت (R/P/S) نمایش داده می‌شود؛ این کمک می‌کند دقیقاً ببینی
  مدل کجا اشتباه می‌کند.
- هر وقت خواستی، کلید `T` را بزن و دوباره وارد حالت تمرین شو؛ نمونه‌های
  بیشتر و متنوع‌تر (نور و فاصله‌ی مختلف، دست کمی چرخیده) بزن و دوباره
  `G` را بزن — مدل قبلی جایگزین می‌شود.
- هر نمونه‌ای که می‌گیری، خودکار چند نسخه (آینه‌ای برای دست چپ/راست +
  چند نسخه با کمی نویز) از آن ساخته می‌شود تا مدل با داده‌ی بیشتری
  آموزش ببیند؛ نیازی نیست خودت صدها نمونه بگیری.
- زاویه‌ی نگه‌داشتن دست دیگر مهم نیست (چه دستت کمی کج باشد چه صاف)، چون
  فیچرها نسبت به چرخش هم نرمال شده‌اند — فقط شکل انگشت‌ها (باز/بسته/دو
  انگشت) روی تشخیص اثر دارد.

## ساختار فایل‌ها
| فایل | نقش |
|---|---|
| `hand_utils.py` | تشخیص اسکلت دست با MediaPipe و استخراج ویژگی |
| `ui_kit.py` | مجموعه‌ی توابع طراحی (پنل، آیکون، اسکوربورد، نوار کلیدها، ...) |
| `audio.py` | افکت‌های صوتی ساده (بدون نیاز به فایل صوتی خارجی) |
| `rps_game.py` | برنامه‌ی اصلی: هم تمرین، هم بازی |
| `gesture_model.pkl` | مدل آموزش‌دیده‌ی تو (بعد از اولین بار تمرین ساخته می‌شود) |
| `hand_landmarker.task` | مدل تشخیص اسکلت دست (بار اول خودکار دانلود می‌شود) |
| `game_data.json` | اسم آخرین بازیکن‌ها و آمار برد/باخت (خودکار ساخته می‌شود) |
| `build_exe.bat` | اسکریپت ساخت فایل اجرایی exe (فقط ویندوز) |

فایل `train_gestures.py` هم همچنان به‌صورت جدا موجود است اگر ترجیح دادی
تمرین را جدا از بازی انجام بدهی، اما دیگر لازم نیست.
